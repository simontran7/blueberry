# Blueberry

Blueberry is a simple and expressive programming language.

[Getting Started](installation.md) shows how to install blueberry, and set up a project. Then, the [Language Tour](hello-blueberry.md) walks through the language one feature at a time, with a short example for each.

> [!CAUTION]
> Sections marked `Unimplemented` describe language design that has been decided but is not yet wired through the compiler.
