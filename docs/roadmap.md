# Roadmap

## Language Features

- Generics
- Product Types (`record`, `tuple`, anonymous tuple)
- Sum Types
- Pattern Matching
- References
- Arrays and Slices
- Strings
- Methods
- Typeclasses with default implementations
- `Option` and `Result`
- Anonymous Function
- Closures
- Iterators
- Visibility
- Type aliases
- Standard Library
- Tail Call Optimisation
- `defer`
- Pipe Operator
- Named Function Arguments
- Green Threads

## Tooling

- x86-64 backend
- WebAssembly backend
- Language server
- Built-in test runner
- Formatter
- Debug info (DWARF)
- Integrated Build System
- Package manager
